# 06_Memory (Memory)

This folder contains the core memory engine specifications, vector database architectures, relational schema designs, memory classification rules, and privacy enforcement rules for JARVIS-X.

## Scope
Defines memory tiers (Short-Term, Working, Long-Term, Session, Semantic, Episodic), hybrid retrieval scoring algorithms, token budgeting, SQLite/ChromaDB storage strategies, and user memory inspection controls.

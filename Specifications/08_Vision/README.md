# 08_Vision (Vision)

## Purpose
This folder contains the vision processing specifications, desktop screen capture drivers, OCR layout parsing engines, UI element detectors, and visual context builders for JARVIS-X.

## Scope
Defines desktop frame grabbing (Desktop Duplication API), OpenCV preprocessing, Tesseract/VLM OCR pipelines, UI bounding box classification, webcam management, and visual privacy protection rules.

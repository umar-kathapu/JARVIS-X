# 09_Agents (Agents)

## Purpose
This folder contains the multi-agent system specifications, specialized agent definitions, DAG task planners, inter-agent communication channels, and tool sandboxing rules for JARVIS-X.

## Scope
Defines built-in specialized agents (Chat, Coding, Research, Browser, Desktop, Memory, Vision, Voice, Email, Calendar, Automation, File System), agent lifecycle stages, parallel execution pipelines, handoff protocols, and fault isolation boundaries.

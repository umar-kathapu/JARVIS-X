# 07_Voice (Voice)

## Purpose
This folder contains the voice processing specifications, wake word detector architectures, speech-to-text (STT) pipelines, neural text-to-speech (TTS) engines, and audio device management rules for JARVIS-X.

## Scope
Defines real-time speech capture workflows, Silero VAD integration, Whisper STT streaming, neural voice synthesis, acoustic echo cancellation, volume ducking, and barge-in interruption handling.

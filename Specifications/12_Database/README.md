# 12_Database (Database)

## Purpose
This folder contains the database architecture specifications, multi-tier storage engines, ER models, SQLite relational schemas, vector embedding store indices, and encryption rules for JARVIS-X.

## Scope
Defines relational storage (SQLite WAL mode), vector store integration (ChromaDB/Qdrant HNSW graphs), in-memory context caching, native OS credential vault storage, automated backup/recovery snapshots, and SQLCipher AES-256 encryption.

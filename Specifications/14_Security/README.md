# 14_Security (Security)

## Purpose
This folder contains the core security architecture specifications, zero-trust validation pipelines, prompt injection sanitizers, RBAC/ABAC authorization rules, encryption protocols, and audit logging specifications for JARVIS-X.

## Scope
Defines 6-layer security validation gates, passkey/biometric authentication, SQLCipher AES-256 encryption at rest, native OS Keyring secret storage, WASM plugin sandboxes, emergency kill-switches (`Ctrl+Alt+Escape`), and cryptographic audit trails.
